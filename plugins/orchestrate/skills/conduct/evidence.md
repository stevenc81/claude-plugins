# Evidence for the routing table

This file holds the numbers and sources behind the "Pick the model" table in SKILL.md. SKILL.md holds the rules, including how to refresh this file ("Refresh the evidence"). This file holds the facts. Do not copy benchmark scores into SKILL.md.

Checked on 2026-10-25 by two checkers per area, on two vendors, plus local tests of the tools. Rows that were not re-checked keep their old date. LiveBench and arena.ai were read with a real browser (Playwright) on 2026-10-25. Arena = arena.ai/leaderboard (Elo ± interval). AA = Artificial Analysis. TB4 = Terminal-Bench 4.0. "Vendor" = the model maker's own number. "Tie" = the intervals overlap. "One source" = no second independent source was found. "One checker" = only one of the two checkers could read the value. Scores are at max effort for Claude and GPT and at high for Gemini, unless the row says otherwise.

Arena notes:
- arena.ai returns 403 to plain web tools. A real browser reads it: only the rendered page shows the Claude rows. One checker read Arena's own dataset on Hugging Face (lmarena-ai/leaderboard-dataset). The live pages were read in a browser on 2026-10-25. Where both read a value, they agree, unless the row says otherwise.
- Arena ranks GPT-6 only at max, Gemini only at high, Opus 5.5 at high on text boards and at max on WebDev and Agent Arena.
- Agent Arena scores are "net improvement": a contrast in percentage points against a randomized baseline that stands for the average model. Positive is above average, negative is below. The board turns every signal so that a higher shown value is better. This holds for tool hallucination too, though its raw rate is "lower is better" (help.arena.ai/articles/5432423882-how-to-use-agent-mode, read 2026-10-25).
- On 2026-10-23, Argon had 10,083 votes on Text overall and 577 on Math. The text boards no longer mark Argon preliminary.

## Known gaps

- Debugging: two small tests run Sonnet 5.5 and Opus 5.5 side by side (Bug Hunt Bench, The New Stack). Both favor Sonnet at max. At xhigh they tie on Bug Hunt. One checker saw a 13-point spread between two identical Bug Hunt runs, and The New Stack reran 4 Sonnet runs. Snorkel and Senior SWE-bench do not test Sonnet 5.5.
- Code review: one source (ReviewBench). It scores products, not models, and the harness moves the score more than the model. GitHub publishes it and sells Copilot. The checkers listed no GPT-6 or Gemini 4 entry.
- Long context: one independent source at about 100k tokens (AA-LCR). No independent test above that. Our measured `agy` compaction (about 169k on Argon) does not match the reports in issue #1245.
- Video: vendor tests only. Audio: one source (Scale AudioMultiChallenge).
- Live web search: two cross-vendor sources (Arena Search, LiveBench Browser Use) that disagree on the vendor order. No test measures a fact check with live search.
- Hallucination: closed-book and grounded tests disagree on Argon (see "Facts and hallucination").
- Argon at medium or low: ARC-AGI and Roboflow only. No coding or writing test at those levels.
- HLE: Scale and AA disagree on Astra vs Opus. Why: not checked.
- The checkers disagree on, or only one could read: the AA TB4 "Astra high 54.0" row; whether gpt-5.6-sol is still on GDPval-AA; the Vals Index fallback toggle; Argon's FACTS Grounding score; the WebDev sub-boards; Terra and Luna on OpenAI's research-debugging eval.
- Not re-checked on 2026-10-25: Vals ProgramBench, Time Horizon, ProofBench, SWE-bench Multimodal and Vibe Code, Roboflow, AA-LCR, the media and audio rows, Parallel.ai and BrowseComp.
- Tool versions: this machine runs `agy` 1.4.7 and Codex 0.164.0. The `agy` compaction and media tests ran on 1.4.3 and 1.4.5. Most `codex exec` tests ran on 0.163.0. On 0.164.0 only the `--json` stream, the flags, `exec resume` access and the profile values were checked.
